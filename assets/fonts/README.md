# Fonts

All fonts are self-hosted, so the page makes no requests to Google or other third parties. Each one is licensed under the
SIL Open Font License 1.1, and its full license text, with copyright notices, sits next to the files.

| Family | Files | License | Source |
|---|---|---|---|
| Manrope | `manrope-latin.woff2` | `OFL-manrope.txt` | Google Fonts, latin subset |
| Bricolage Grotesque | `bricolage-grotesque-latin.woff2` | `OFL-bricolagegrotesque.txt` | Google Fonts, latin subset |
| EB Garamond | `eb-garamond-latin.woff2` | `OFL-ebgaramond.txt` | Google Fonts, latin subset |
| Pixelify Sans | `pixelify-sans-latin.woff2` | `OFL-pixelifysans.txt` | Google Fonts, latin subset |
| Azeret Mono | `azeret-mono-latin.woff2` | `OFL-azeretmono.txt` | Google Fonts, latin subset |
| Saira Condensed | `SairaCondensed-Bold.ttf`, `SairaCondensed-ExtraBold.ttf` | `OFL-sairacondensed.txt` | github.com/google/fonts, original files, unmodified |

Saira has the Reserved Font Name "Saira". The OFL counts subsetting as a modification, and a modified version may not use a
reserved name, so Saira Condensed ships as the original unmodified TTF files. Do not subset or convert them.
Fonts without a reserved name are served as Google's latin subsets.
